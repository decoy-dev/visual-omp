# omp 18.14 TSP capture

`omp-18.14.bin` is an unmodified copy of `/tmp/tsp-study/raw.bin`, captured from the installed executable reporting `omp/18.14.0` in a scratch git repository. The matching upstream protocol and reference applier source is tag `v18.14.0`, commit `31147f9d1a76608549821c3759f8487b4d66c72d` of [oh-my-pi](https://github.com/can1357/oh-my-pi/tree/31147f9d1a76608549821c3759f8487b4d66c72d).

The capture contains ordinary terminal controls, the hello query, an inline `omp.session` surface, editor readiness frames, empty `/btw` history, overlay dismissal and `/exit` with retained close. The initial capture opened `/btw` through bracketed paste and Enter. The separate current live integration probe verifies the same overlay through the semantic submit path. No side question or model prompt was submitted.

The source probe used isolated HOME and config directories, removed inherited token/API-secret variables, and loaded no credentials. It disabled extensions, skills, rules, context files, LSP and title loading. `TERM_PROGRAM=tern` and `PI_TUI_NATIVE=1` enabled the source capture. Its temporary config disabled setup, update/changelog checks, startup worktree creation, automatic graphing and autocomplete, with worktree exit set to keep. The production preview removes `PI_TUI_NATIVE` rather than forcing it; the current live probe uses that launch policy.

No post-capture redactions or transformations were applied. Tests replay the fixture as bytes with multiple read boundaries, compare passthrough bytes, and apply its semantic frames using the vendored MIT-licensed reference applier. Absolute scratch paths are not used by the test code.
