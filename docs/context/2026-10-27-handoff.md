## Dock badge investigation (resolved, no code bug)
The owner saw no Dock badge in the installed 0.6.5. The app did set it: the saved layout held one unopened chat, and a dev build with a completed reply set the badge to "1". The cause was macOS notifications being off for visual-omp. This was observed on the owner's Mac; behavior on other macOS versions was not checked. The badge appeared as soon as the owner allowed notifications. `lsappinfo info -only StatusLabel` shows nothing even for an app whose badge is set, so it is no evidence either way.
