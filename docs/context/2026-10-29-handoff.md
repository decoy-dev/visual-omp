## Known limits recorded in the audit
- omp 18.14 does not report startup input readiness, so `worktree.onStart: "off"` stays pinned.
- `get_login_providers` omits `storeCredentialsAs`; exact provider alias grouping is blocked.
- `omp config list --json` carries no UI condition, so Tern-only settings stay visible in Advanced.
- omp's collab `SessionState` has no background-wait flag, so a wait that began before a reconnect is not shown.
- `OMP_TUI_DEBUG` reaches tool environments; scoping it needs an omp change. The relay cannot carry a path token because omp normalizes relay URLs.
- Windows keeps Electron's RunAsNode fuse because node-pty's console cleanup needs it.
- Microphone capture through the new dictation path has not been tested because no speech model was downloaded.
