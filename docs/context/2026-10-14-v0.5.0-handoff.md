## Technical notes

- **Size:** the macOS arm64 app is 242.5 MiB, of which the Electron framework binary is 192.1 MiB, Electron's resources 25.4 MiB (with `resources.pak` 11.8 MiB and `icudtl.dat` 10.4 MiB) and its libraries 17.9 MiB (SwiftShader 15.8 MiB). visual-omp's own `app.asar` is 3.9 MiB and node-pty 0.2 MiB. Removing SwiftShader would save about 16 MiB at the cost of Chromium's software rendering fallback, and only a different shell would change the order of magnitude.
- **Intel build on Apple silicon:** macOS 27 warns that the Intel build "will not open in macOS 28", since Rosetta ends for general apps after macOS 27. Under Rosetta the app's git calls also fail, because the Command Line Tools on macOS 27 ship `libxcrun.dylib` without an x86_64 slice, so the status bar shows "No git". Real Intel Macs run macOS 26 or older and are not affected. The updater picks the installer by `process.arch`, so a copy installed by mistake keeps updating to the Intel build; the owner chose to leave this as it is.
- **"Show new activity":** in the Intel run the button stayed visible although the transcript did not overflow. `5da7306` treats a view exactly at the bottom as pinned. The cause of the false unpin was not found; two attempts on Apple silicon with scroll and input logging did not reproduce it.
- **Parallels access:** the VM is encrypted, so `prlctl exec` reads the VM password from standard input (`printf '%s\n' "$PW" | prlctl exec "Windows 11" --current-user …`). Without `--current-user` commands run as `NT AUTHORITY\SYSTEM`. A long build started directly through `prlctl exec` stopped partway through without an error, so long jobs run detached with PowerShell `Start-Process` and report through a log file. `git clone` from `\\Mac\Home` needs `-c safe.directory=*`. The password is not stored in the repository or on disk.
- **Driving packaged builds:** the packaged renderer cannot import `state/app.ts` from the console, so the smoke tests drove the real UI with CDP mouse and keyboard events. ⌘K is a native menu accelerator and does not reach the page through CDP; click **Search commands** instead. `SIGTERM` quits the macOS app gracefully, and its omp and shell children exit with it.
