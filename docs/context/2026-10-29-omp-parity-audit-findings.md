No impact: roughly 380 of about 405 changelog bullets. They cover provider and catalog fixes, natives, UI that exists only in Tern or its native protocol (`PI_TUI_NATIVE=0`), internal and SDK APIs, RPC-only additions, and settings that Advanced settings lists automatically from `omp config list --json` (for example `gc.stale`, `tools.artifactMaxBytes` and the `task.completionProbe` rename). Report panels, `/effort` and `/modelpreset` are already covered per `docs/COMMANDS.md`.

Couldn't determine:
- **Home-folder chats:** The app's project scope reads and writes `<cwd>/.omp/config.yml` (`main/omp/config-file.ts:50-51`). omp 18.4.11 no longer treats `~/.omp` as a project anchor (`discovery/helpers.ts:1050-1057`), but I didn't confirm that omp's settings loader ignores `~/.omp/config.yml` when the folder is home. To settle it: save a project-scope value from the app for a chat in `~`, then check `source` in `omp read cfg://<key>` there on 18.13.3.
- **Idle recaps:** I traced from omp 18.14.0 source that recaps run in the hidden TUI, but didn't see one happen. To settle it: leave an app chat idle for more than 4 minutes with the terminal sheet open.
- **RPC fork while the chat is live:** I don't know if a second process running `fork` writes to or claims the source file while the chat's own omp has it open. To settle it: run the fork on 18.13.3 and check the source file with lsof and its mtime.
- **Lease names on Linux and Windows:** The socket and mutex names come from `@oh-my-pi/pi-utils/file-lock`, which isn't in the unpacked package. To settle it: read that module from pi-utils 18.14.0.
