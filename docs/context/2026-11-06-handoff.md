## Process notes from today

- New owner rule (in AGENTS.md and RELEASING.md): before a release, open the dev build with `npm run tour -- --release X.Y.Z` on the release commit so the owner can try every change in ready-made chats.
- Worktrees get an APFS-cloned `node_modules` from a checkout hook. Always `rm -rf <worktree>/node_modules && ln -s /Users/chrishaddox/visual-omp/node_modules <worktree>/node_modules`; a nested link produced a duplicate React and a blank packaged renderer in the Windows build.
- A shell pipeline ending in `| head` hides a failing exit status; gate merges on the test command's own result (one merge today had to be followed by a test fix, `dcb741a`).
- The dev window reports `document.hidden` when other windows cover it, which pauses chat rendering by design; launch with `--disable-backgrounding-occluded-windows --disable-renderer-backgrounding` for CDP checks.
